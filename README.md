Хранилище данных жилого фонда (данные ГИС ЖКХ).

Проект представляет собой хранилище данных для анализа жилого фонда на основе данных об износе и аварийности ГИС ЖКХ (Государственная информационная система жилищно-коммунального хозяйства). 

Реализован полный цикл обработки данных: от загрузки исходного файла до построения витрин и аналитических дашбордов.

Стек технологий:
СУБД: PostgreSQL 15
Загрузка и трансформация: Python 3 (pandas, psycopg2)
Оркестрация: Prefect
Визуализация: Apache Superset
Контейнеризация: Docker

Структура хранилища:
Хранилище построено по схеме «звезда» и состоит из трёх слоёв.
Слой 1 Staging (stg_houses) - Сырые данные, загруженные из внешнего источника
Слой 2 Core / логический слой (fact_houses, dim_) - Таблица фактов и таблицы измерений
Слой 3 Витрины данных (marts_*) - Готовые таблицы для аналитики и отчётности

Основные таблицы:
fact_houses  - центральная таблица фактов (данные о домах).
dim_region  - измерение «Регион».
dim_municipality -  измерение «Муниципалитет».
dim_house_type  - измерение «Тип дома».
dim_house_condition - измерение «Состояние дома».
dim_energy_efficency_class  - измерение «Класс энергоэффективности».
dim_management_organization  - измерение «Управляющая организация».
dim_life_cycle_stage - измерение «Стадия жизненного цикла».
dim_date  - календарное измерение (для аналитики по времени).

Витрины данных:
marts_by_houses_full  - детальная витрина по всем домам.
marts_by_region  - сводка по регионам.
marts_by_year  - сводка по годам постройки.
marts_by_management  - сводка по управляющим организациям.
marts_by_energy_class - сводка по классам энергоэффективности.

Структура репозитория:
.
├── data/                      # исходные данные (CSV)
├── sql/                       # SQL-скрипты (DDL, витрины)
│   ├── ddl.sql                # создание таблиц схемы «звезда»
│   └── marts.sql              # построение витрин
├── scripts/                   # Python-скрипты
│   ├── reload_data_3_from_stage.py   # загрузка и трансформация
│   └── build_marts.py                 # построение витрин
├── orchestrator/              # оркестрация
│   └── prefect_flow.py        # поток Prefect
├── docker-compose.yml         # окружение (PostgreSQL, Superset)
└── README.md                  # описание проекта

Данные:
Исходный файл содержит более 956 тысяч записей о жилом фонде: адреса, площади, год постройки, физический износ, класс энергоэффективности, сведения об управляющих организациях и др.
Примечания:
Файлы исходных данных (CSV) не загружаются в репозиторий из-за большого объёма.
